# 🔥 ember.fyi — $EMBER Metrics, Scored Live

Live, source-linked metrics and burn analytics for **$EMBER** (`5dvXTZ5qwgafnHtwu3Ls3QrWx1U4LQsFeCuJgkk4QEC6`), the platform token of the EmberCurve launchpad on Solana.

Designed to mirror the comprehensive analytics and aesthetic of **stonk.fyi**.

---

## ⚡ Features

- **Live Ticker & Header**: Live on-chain price, market cap, 24h volume, burn percentage, and pending burn balance.
- **Structural Supply & Burn Donut**: Interactive circular gauge showing the one-way supply deflation from 1.00B initial supply.
- **Bull-Case Scorecard**: 16 indicators scored live across Flywheel, Demand, Holders, and Valuation.
- **Recent Burns Feed**: Live transactions from the burn wallet (`GZjYfGyUNQfDChcQ66Gc3ZMcQqPEisyRYe1nPyQhP9bp`) with direct Solscan links.
- **Flywheel Simulator**: Interactive constant-product AMM projection simulator (Growth rate, Horizon, Pool depth).
- **Tokens Priced in EMBER**: Ecosystem launchpad launches paired with EMBER (FLAME, LOTTO, LIT, CHARMANDER, REBME, etc.).
- **All EMBER Pools**: 30+ liquidity pairs across Meteora DLMM, Raydium CLMM, and Orca Whirlpools.

---

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Styling**: Tailwind CSS v4
- **Charts**: Recharts
- **Icons**: Lucide React
- **APIs**: Solana JSON-RPC & DexScreener DLMM API
