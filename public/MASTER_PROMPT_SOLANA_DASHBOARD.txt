SECTION 4: CORE API ROUTES (Zero-Rate-Limit Architecture)
================================================================================

1. src/app/api/token/route.ts (Aggregated Token Metrics):
- Query DexScreener API: https://api.dexscreener.com/latest/dex/tokens/{TOKEN_MINT}
  Extract: priceUsd, priceChange.h24, volume.h24, fdv, liquidity.usd, and pairs list.
- Query Solana Public RPC: https://api.mainnet-beta.solana.com (method: getTokenSupply with { mint: TOKEN_MINT })
  Calculate:
  * circulatingSupply = tokenSupply.uiAmount
  * burnedSupply = INITIAL_SUPPLY - circulatingSupply
  * burnedPercentage = (burnedSupply / INITIAL_SUPPLY) * 100
  * marketCap = circulatingSupply * priceUsd
  * volume24h = sum of all pairs 24h volume
  * liquidity = sum of all pairs liquidity
- Fallback: Always cache the last successful response so the frontend NEVER crashes on transient RPC 429s.

2. src/app/api/burns/route.ts (Verified Action: BURN On-Chain Tracker):
- CRITICAL MANDATE:
  Do NOT return generic wallet transactions (e.g. Transfers of random tokens or Fees: Claim).
  Filter STRICTLY for on-chain Action: BURN SPL Token instructions:
  ix.program === "spl-token" && (ix.parsed?.type === "burn" || ix.parsed?.type === "burnChecked") && (ix.parsed?.info?.mint === TOKEN_MINT).
- Every burn item MUST return:
  { signature, shortSig, slot, blockTime, relativeTime, action: "BURN", token: TOKEN_SYMBOL, emberAmount, amount, usdValue, solscanUrl, isEmber: true }
- Provide solscanBurnLedgerUrl:
  https://solscan.io/account/{BURN_WALLET}#transfers?activity_type=ACTIVITY_SPL_BURN
- Use AbortSignal.timeout(5000) on all RPC requests to prevent serverless execution hangs.
- Maintain an in-memory verified ledger seeded with authentic on-chain burnChecked transactions, and dynamically poll for new ones.
